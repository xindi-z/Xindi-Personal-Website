# 技术实施标准
React + TypeScript + Vite + Tailwind CSS；使用 lucide-react 图标。静态前端，无后台。
src/data/portfolio.ts 保存个人信息、教育、技能、经历、项目及可选链接。
components 放复用组件，sections 放内容区，styles 放主题及响应式规则。
语义 HTML、可见键盘焦点、跳过导航、减少动画偏好、移动菜单 Escape 关闭。
简历原件在 public 中供下载，不修改原件；不引入远程字体或第三方跟踪。
空链接不渲染。外链使用安全 rel。部署路径可通过 Vite base 配置。
运行 npm run build 进行类型检查和打包；npm run dev 启动本地预览。

## GitHub Pages 发布准备
使用 GitHub Actions 手动触发，Node 22、npm ci、生产构建后仅上传 dist。默认分支 main。保留已删除 deploy.yml 的用户改动，新建 pages-manual.yml。public 仅保留对外发布资源，Word 简历移至忽略的 local-only。
