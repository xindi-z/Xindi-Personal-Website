# Design Standards
Use a near-black navy background, off-white headings, and restrained ice-blue accents. Prefer thin borders, generous spacing, and numbered editorial sections.
The hero introduces the owner and role on the left, with code and a technical flow diagram on the right. Do not use fabricated project screenshots.
Differentiate projects through typography, categories, numbering, and technical flows.

Target at least 16px for body copy, 14px for frequently used labels, and 12px for secondary metadata.
Use two columns on desktop, reduced spacing on tablets, and one column on phones. Collapse navigation on narrow screens and support keyboard interaction.
Keep motion limited to hover and smooth scrolling, respecting prefers-reduced-motion.
Use concise, factual English. Avoid unsupported expert or senior claims.

## Pixel details
Limit the initial pixel treatment to the xz monogram and hero code panel: stepped corners, square terminal details, and a static block cursor.
Reuse the monogram in the footer. Keep modern body typography, the blue palette, and no blinking animation or additional font dependencies.

## Light and dark themes
Provide a keyboard-accessible theme button in navigation. Default to dark and remember the local preference.
Use cool-white backgrounds, navy text, and blue accents in light mode. Retain dark terminal and project visuals for readability.
