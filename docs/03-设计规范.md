# 设计规范
视觉：近黑蓝背景、偏白大标题、克制冰蓝强调色。细边框、大留白、编辑式编号章节。
首屏左侧清晰介绍姓名与角色，右侧以代码和系统流程图体现技术方向，不使用假项目截图。
项目区通过编号、分类、技术流程图及排版形成差异，不能看起来像图片占位。
正文至少 16px，常用标签至少 14px，次要元信息至少 12px。
桌面双栏，平板收敛间距，手机单栏；导航在窄屏折叠；所有交互支持键盘。
动效仅 hover、平滑滚动，遵守 prefers-reduced-motion。
内容简练、可信、全英文，不使用 expert/senior 等无依据表述。

## 2026-09-10 章节顺序
Education 为 01，About 为 02，Experience 为 03，Projects 为 04，Interests 为 05，Contact 为 06；导航顺序与实际页面一致，移除 Skills 导航。

## Skill Set 顺序
Education 01、Skill Set 02、About 03、Experience 04、Projects 05、Interests 06、Contact 07。技能使用现有响应式分组布局；导航在 Education 后加入 Skills，简历按钮格式标记 PDF。

## 局部像素风
第一步仅调整字标和首页代码面板：像素网格 xz 字标、阶梯边角、方形终端标记和静态方块光标。正文仍使用现代字体，保留冰蓝色与深色底；无闪烁动画，无额外字体依赖。页脚复用相同字标保持一致。

## 深浅色切换
导航加入键盘可操作的深浅色按钮，默认深色，保存本机偏好。浅色使用冷白背景、深蓝正文与蓝色强调，像素终端保留深色显示，保证代码可读性。
